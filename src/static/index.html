Usage preferences for automatic routing

            

              
              
            

            
Providers the automatic workflow may use

            
No provider is opted in automatically. These permissions apply to automatic routing; an explicit single-provider task uses the provider you select. A remote provider can receive the goal and generated context and may charge for usage. “Free” hosting is governed by its provider, not this app.

            
            

          

          

            
Credential storage

            
Existing OPENAI_API_KEY and ANTHROPIC_API_KEY environment variables take precedence and skip first-time setup.

            
Save new keys to the OS credential store, or keep them in API-server memory until restart. Server-memory credentials are shared by local clients and are lost on reload.

            
Only non-secret preferences are saved in JSON. API keys are never saved in browser storage or returned by the settings API.

            
API access may require separate billing. ChatGPT and Claude subscriptions do not automatically include API access. Provider sign-in is not supported here yet.

            
Local HTTP is supported only on loopback addresses. Other servers need HTTPS. Start your local server and install/load its models first; this app does not download models or start inference servers. Local only excludes recognized Ollama cloud models and checks native model metadata before generation. A custom local proxy can still forward remotely—only configure servers you trust. Model listing is not proof that a model can follow structured planning instructions.
