Credential storage

            
Existing OPENAI_API_KEY and ANTHROPIC_API_KEY environment variables take precedence and skip first-time setup.

            
Save new keys to the OS credential store, or keep them in API-server memory until restart. Server-memory credentials are shared by local clients and are lost on reload.

            
Only non-secret preferences are saved in JSON. API keys are never saved in browser storage or returned by the settings API.

            
API access may require separate billing. ChatGPT and Claude subscriptions do not automatically include API access. Provider sign-in is not supported here yet.
